# 지식 문서 인덱스

작업과 관련된 문서를 아래에서 찾아 필요한 부분만 읽는다. 색인의 설명만으로 후보를 정하기 어렵거나 필요한 근거가 없으면 질문의 증상·기술 식별자로 `.knowledge` 본문을 검색한다. 검색 후보에 포함되는 것과 답변의 근거가 되는 것은 다르므로 해당 절을 직접 확인한다.

지식 문서를 추가하거나 이름·내용을 바꾸면 제목과 설명도 함께 갱신한다. 날짜가 붙은 검증·배포 기록은 당시 결과이며, 현재 구현은 연결된 소스와 대조한다. 과거 설계는 현재 작업 지침으로 적용하지 않는다.
