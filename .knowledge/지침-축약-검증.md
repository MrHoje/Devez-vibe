# 기본·역할 지침 축약 검증

Planner만 단계별 문서를 사용하고 Goal Runner·Builder·Reviewer·Researcher는 통합 본문을 사용한다. [src/agent.rs](../src/agent.rs)와 [역할 원문](../prompts/agents/builder.md)이 현재 기준이다. 2026-09-10 전후의 축약 계측표와 실모델 출력 시험 회차 기록은 일회성 결과라 삭제했으며 필요하면 git 이력에서 본다.

Builder의 현재 제한은 공백·탭·줄바꿈 제외 200자이며 선택·승인 설명·코드 블록과 명시적 상세 분석 요청에 예외가 있다. 자동 지식의 읽기·쓰기 구분은 [자동 지식 기록과 문서 검색](자동-지식-기록과-검색.md)을 따른다.

## 2026-09-12 Builder 지침 영어 통일

- Builder의 `응답 분량` 절과 `src/agent.rs`의 역할 전환 문장을 영어로 바꿨다. 규칙 내용은 그대로이며 한국어 출력 의무는 공통 지침이 유지한다.
- 실제 주입되는 Builder 블록은 o200k_base 기준 **514 → 454토큰**(문자 1,693 → 2,411)이다. 계측은 `DEVEZ_ROLE_FIXTURES`로 `export_role_guide_fixtures`를 돌려 얻은 블록을 그대로 세었다.
- 같은 지침을 한국어로 통일하면 611토큰으로 더 늘어난다. 한글은 문자 수가 적어도 토큰 효율이 낮아 영어보다 불리하다. cl100k_base에서는 격차가 더 크다(영어 436, 한국어 945).
- 계측용 `tiktoken`은 사용자 환경에만 설치했고 제품 의존성에는 넣지 않았다. OpenAI 인코딩은 Claude 토크나이저가 아니므로 절대값이 아니라 언어별 경향의 대리 지표다.
- 문구가 바뀌면서 `agent.rs`·`backend.rs`의 지침 검사 테스트 문자열도 영어로 갱신했다. 전체 `cargo test` 1,323건 통과다.
- 영어 전환 뒤 실제 모델의 한국어 응답·200자 준수율이 같거나 나아졌다는 검증은 하지 않았다.

## Claude 자동 후속 턴의 언어 상태

- Task 알림처럼 새 사용자 입력 없이 시작되는 후속 턴은 새 리마인더를 붙이지 않고 직전 요청의 `koreanRequest`를 상속한다. 그래야 한국어 요청에서 짧은 `Now...` 진행문을 숨기는 기존 보정이 계속 적용되며 프롬프트 길이는 늘지 않는다.
- `beginTurn`의 입력 생략과 명시적 영어 입력을 구분한다. 전자는 저장한 언어 상태를 이어받고, 후자는 새 입력을 판별해 영어 진행문을 보존한다.
