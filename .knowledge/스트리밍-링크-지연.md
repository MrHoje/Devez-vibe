# 스트리밍 링크의 표시 지연

적용 범위는 이미 수신된 응답의 화면 출력 속도다. 확인 위치는 [src/renderer.rs](../src/renderer.rs)의 `hidden_streaming_link_range`, [src/state.rs](../src/state.rs)의 `TextPace`와 관련 시간 순서 시험이다. 네트워크 대기와 구분하며, 실제 SDK 구독 한도 대기는 [Claude SDK 문서](Claude-Agent-SDK-호환성-업데이트.md)를 본다.

- 링크 주소를 화면에서 숨겨도 `TextPace`가 원문을 한 글자씩 처리하면 다음 문장 앞에서 멈춘다. `stream_fade_tail`까지 원문 길이를 세면 이미 표시한 링크가 다시 흐려진다.
- `hidden_streaming_link_range`로 숨긴 주소만 속도·밝기 계산에서 제외한다. 렌더러와 같은 링크·코드 분석을 사용하며 코드·인용문·표·표시 이름 없는 주소는 임의로 건너뛰지 않는다. 저장 원문은 그대로 보존한다.
- 주소만 갱신돼도 클릭 대상과 줄 번호는 다시 그려야 한다. `links_changed`로 다시 그리기를 요청하고, 완료 직전 화면을 한 번 유지하는 기존 처리를 거친다.
- 정지 화면 시험만으로는 출력 지연을 잡을 수 없다. 이미 도착한 입력을 40ms 단위로 처리하는 시험에서 짧은 주소와 4,096자 주소 뒤의 다음 단어가 나타나는 시간을 비교한다. 이 재현 조건에서 수정 전 720ms·2,880ms, 수정 후 모두 160ms였다. 모델·네트워크의 실제 수신 대기 시간은 별개다.
