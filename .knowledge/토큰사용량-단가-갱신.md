# 토큰 사용량 비용($) 단가 — 갱신 프로세스

## 현재 구현과 적용 범위

2026-09-11 `ac99985` 소스 기준이다. 내부 추정 비용 계산은 유지되지만 **현재 컴포저 상단에는 비용을 표시하지 않는다**. `ComposerMode.cost`에 값이 있어도 `full_badge_spans`는 비용을 그리지 않으며 `estimated_cost_is_not_shown_above_the_composer`가 이를 검증한다. 과거의 `금액 · 모드 · Fast` 표시·축약 순서를 현재 UI로 설명하지 않는다.

이 문서는 [src/pricing.rs](../src/pricing.rs)의 구현을 설명한다. 코드에 저장된 단가가 제공자의 현재 공식 가격이나 실제 청구액과 일치함을 보장하지 않는다. 단가 변경 시 공식 요금표의 조회 날짜·모델·입력·출력·캐시 요율을 새로 대조한다. 다른 제품과의 일치도 실제 단가표·집계 경로를 비교한 뒤 판단한다.

## 계산 흐름

| 요소 | 확인 위치 | 현재 동작 |
| --- | --- | --- |
| 모델 단가 | `src/pricing.rs`의 `PRICES` | 모델 이름을 소문자로 바꾼 뒤 부분 문자열의 첫 일치 사용 |
| 입력 분리 | `TokenTotals::from_breakdown` | 전체 입력에서 캐시 읽기·쓰기를 포화 뺄셈으로 제외 |
| 모델별 누적 원장 | `CostLedger::record_cumulative` | 이전 누적값과의 증가분을 당시 활성 모델에 귀속 |
| 총 추정 비용 | `CostLedger::estimate_usd` | 사용 모델별 비용을 합산하며 단가 미상 구간이 있으면 `None` |
| 상태와 복원 | `src/state.rs`의 `active_cost_model`, `apply_restored_cost`, `estimated_cost` | 활성 턴 모델과 복원 원장을 사용하며 원장 없음·0 이하 비용은 표시 문자열 없음 |
| 화면 | `src/renderer.rs`의 `full_badge_spans` | 현재 비용 배지 미표시 |

- `total.*`은 비용용 누적 입력이며 `last.totalTokens`는 컨텍스트 사용량이다. 두 값을 혼용하지 않는다. [컨텍스트 복원](컨텍스트-표시-복원.md)을 함께 본다.
- `reasoningOutputTokens`는 `outputTokens`의 일부이므로 다시 더하지 않는다.
- `TokenTotals`는 camelCase·snake_case 필드를 수용한다. 외부 제공자 계약은 해당 버전의 스키마와 브리지 변환을 별도로 확인한다.
- Devez Vibe의 이 계산에는 사용자 단가 설정을 읽는 경로가 없다. 현재는 코드 수정과 재빌드가 필요하다.

## 단가 변경 시 확인할 사항

1. [Codex 호환성](Codex-CLI-호환성-업데이트.md) 또는 [Claude SDK 호환성](Claude-Agent-SDK-호환성-업데이트.md) 절차로 실제 모델 식별자를 확인한다.
2. 구체적인 모델을 일반 계열보다 먼저 둔다. `gpt-5.6-luna`보다 `gpt-5.6`을 앞에 두면 이 소스의 입력·출력 단가가 각각 25배로 계산된다. 과거 문서의 6배 설명은 잘못된 산술이었다.
3. 캐시 쓰기 기본 배수는 `1.25`, 읽기는 `0.1`이다. **`claude-fable-5-1`의 읽기 배수는 `0.025`인 별도 분기**가 있다. 전 모델 공통이라고 가정하지 않는다. 이는 코드의 계산값이지 현재 제공자 요금의 확인 결과가 아니다.
4. 캐시 보존 시간·서비스 등급·모델별 요율이 별도로 필요한 경우 현재 코드가 그 구분을 하는지 확인한다. 추정에 없는 구분을 이미 지원한다고 설명하지 않는다.
5. DevezCode와 같은 금액이 필요하면 그 저장소의 실제 위치·설정·모델별 집계도 대조한다. 예전 PC의 절대 경로나 동일 표라는 설명만으로 일치를 단정하지 않는다.

## 검증

저장소 루트에서 실행한다.

```powershell
cargo test pricing::tests
cargo test composer_badge_reports_an_estimated_cost_from_the_billed_totals
cargo test estimated_cost_is_not_shown_above_the_composer
```

기대값은 독립적으로 계산한다. 모델 우선순위, 캐시 분리·예외 요율, 모델 변경 시 원장, 단가 미상 구간, 출력의 추론 토큰 이중 합산 여부를 확인한다. 실제 출력값을 그대로 기대값으로 복사하지 않는다.

비용 관련 변경을 배포할 때는 [배포 절차](배포-버전-갱신.md)를 따른다. 문서 정비만으로 단가·화면·제품 버전을 변경하지 않는다.
