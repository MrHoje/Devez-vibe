# 화면 문구 언어 기준

## 기준

- 알림·블록·오버레이 제목, 승인 선택지·버튼·단축키 힌트, 짧은 상태 라벨은 두 언어 모두 영어로 쓴다.
- 문장형 설명(슬래시 명령·선택 창 설명·`/help`), 알림 본문, 컴포저 알림(복사·초안 보관 등), 오류 메시지, 빈 목록 안내는 `/language`에 따라 바뀐다. 기본은 한국어이고 설정은 settings.toml의 `language`에만 저장하며 Codex config.toml로 대체 조회하지 않는다.
- 이름 옆에 붙는 상태 단어(`· On`, `· enabled`)는 라벨로 보고 영어로 두되, `already enabled`처럼 구절이면 두 언어로 쓴다.
- 새 문구는 `crate::language::tr("한국어", "English")`로 두 벌을 함께 쓴다. `format!`이 필요하면 `tr(format!(…), format!(…))`처럼 두 문장을 모두 만든다.
- 예외: 로그인 만료 안내 본문은 사용자 요청(2026-10-02)에 따라 언어 설정과 무관하게 영어로 쓴다. MCP는 `src/integrations.rs`의 `failure_detail`, 턴 오류는 `src/state.rs`의 `provider_error_text`가 만든다.
- 제공자 오류 원문은 화면에 그대로 넣지 않는다. `src/app_server.rs`의 `condense_error_message`로 HTML을 자르고 JSON 본문은 안쪽 `message`만 남겨, 앞 두 줄을 줄마다 200자로 줄인다. Claude 안전장치 판별처럼 원문 비교가 필요한 곳은 축약 전 문자열을 쓴다.
- `dvz doctor` 보고서와 `dvz update` 진행 표시는 라벨까지 설정 언어를 따른다. What's New는 `RELEASE_NOTES`와 `RELEASE_NOTES_EN` 중 하나를 표시한다.
- Node 브리지(`npm/bridge`)와 제공자가 보낸 오류 문구는 언어 설정을 따르지 않는다.
- 개수가 붙는 영어 라벨은 `1 tool`/`2 tools`처럼 단수·복수를 나눈다.

## 바꾸면 안 되는 한글 값

화면에 보이더라도 모델이나 외부 도구와 주고받는 값은 문자열을 비교하므로 그대로 두고 `tr()`로 감싸지 않는다.

- Codex가 보내는 계획 제목 `작업 단계`: 비교만 하고 화면에는 `Updated Plan`으로 바꿔 표시한다.
- 질문 머리 기본값 `질문`: 브리지와 Codex 질문 파싱이 채운다. 표시 함수가 `Question`·`Question N`으로 바꾼다.
- Planner 선택지 `Goal Runner로 실행`: `prompts/agents/planner*.md`가 모델에게 이 라벨을 내보내게 한다.
- 제공자 인계 계획의 `[완료]·[진행 중]·[대기]`, 인계 기록의 `사용자`·`도우미` 같은 이름: 다음 모델에 보내는 문장이다.
- 한글 자판 단축키 자모(`'ㅁ'`, `'ㄴ'` 등), `(권장)`·`(추천)` 제거 비교, 오류 문장 일치 검사(`Claude 세션을 찾을 수 없습니다`).
- 서버에 돌려보내는 `Action::RpcError` 메시지, 브리지가 문장 일부로 비교하는 `사용자 입력 화면에 전달하지 못했습니다`, 질문 답변을 모델에 넘기는 `질문에 대한 사용자 답변`.

## 누락 없이 찾는 방법

- `Block::new(kind, "제목")` 같은 리터럴 인자만 검색하면 빠지는 곳이 생긴다. `let title = match … => "경고"`처럼 변수를 거쳐 제목을 만드는 경로는 이 검색에 걸리지 않는다.
- 테스트 모듈과 주석을 뺀 한글 문자열 리터럴을 전부 뽑은 뒤 분류하면 빠지지 않는다. `push_notice`의 두 번째 인자, `title:`·`label`·`detail` 필드, `match` 분기 값을 함께 본다.
- 두 언어화 누락은 문자열 리터럴 중 `tr(…)` 괄호 범위 밖에 있는 한글·영어 문장을 뽑아 찾는다. 줄 단위 검색은 여러 줄에 걸친 `tr(` 호출과 `\` 줄 이음 문자열을 놓친다.
- 문자열을 바꾼 뒤에는 전체 `cargo test`를 돌려 한글 기대값이 남은 테스트를 찾는다. 테스트 입력으로 쓰인 같은 한글이 함께 바뀌어 기대값이 어긋날 수 있으니, 실패한 줄마다 입력인지 기대값인지 확인한다.
- 시험은 기본 언어인 한국어로 돈다. 언어 전역값은 시험에서 스레드별이라 `language::set_english(true)`를 부른 시험만 영어로 바뀐다.
