1. 한 줄 정의

여러 AI 코딩 세션을 한 창에서 프로젝트별로 관리하고, 각 세션이 지금 무엇을 하고 있는지 추적하며, 사용량을 실시간으로 확인하는 Windows 데스크톱 앱이다. 터미널을 흉내 내는 것이 아니라 실제 터미널 위에서 세션이 그대로 돌아간다.

프로젝트별 세션 관리

세션이 프로젝트에 묶여 정리된다. 여러 저장소를 오가도 섞이지 않는다.

세션 상태 추적

작업 중인지, 내 답을 기다리는지, 끝났는지를 목록에서 바로 구분한다.

실시간 사용량 확인

세션별 토큰과 비용이 헤더에서 실시간으로 집계된다.

2. 프로젝트별 세션 관리

  • 프로젝트 트리와 세션 목록 — 좌측에서 작업 중인 프로젝트를 고르면 그 프로젝트에 속한 세션만 보인다. 세션이 어느 저장소에서 시작됐는지 기억할 필요가 없다.
  • 탭으로 동시 실행 — 여러 세션을 탭으로 띄워 놓고 필요할 때 오간다. 한 세션이 오래 도는 동안 다른 세션에서 계속 작업할 수 있다.
  • 세션 이어가기 — 앱을 껐다 켜도 세션 구성이 유지되고, 이전 대화를 그대로 이어서 재개할 수 있다.
  • 세션 관리 · 정리 · 내보내기 — 쌓인 세션을 목록에서 정리하고, 필요한 대화는 파일로 내보낸다.
  • 앱 밖 세션 끌어오기 — 별도 터미널에서 시작한 세션을 앱 안으로 가져와 같은 방식으로 관리할 수 있다.
  • 파일 빠른 열기 — 프로젝트 파일 색인을 두고 이름 일부만으로 바로 연다.

3. 세션 동작 상태 추적

세션 목록만 보고도 지금 무엇을 봐야 하는지 판단할 수 있게 상태를 구분해 표시한다.

상태표시의미
작업 중스피너세션이 실제로 돌고 있다. 기다리면 된다.
응답 대기❗ 배지세션이 사용자 답을 기다리며 멈춰 있다. 내가 가야 진행된다.
완료완료 기록 카드작업이 끝났다. 결과를 확인하면 된다.
  • 상태는 화면 글자를 짐작해 판단하지 않는다. 세션이 실제로 바쁜지를 훅이나 상태 파일로 직접 확인해 표시한다.
  • 마지막 프롬프트를 세션 헤더에 표시해, 탭을 열어 보지 않아도 무슨 일을 시켜 둔 세션인지 알 수 있다.
  • 알림 팝업으로 상태 변화를 창 밖에서도 알린다.
  • 작업 대기열에 할 일을 쌓아 순서대로 처리한다.

4. 실시간 사용량 확인

  • 세션별 입·출력 토큰과 비용을 헤더에서 실시간 집계한다. 어떤 작업이 얼마를 썼는지 끝나고 나서가 아니라 진행 중에 보인다.
  • 사용 한도 스냅샷을 보관해 남은 여유를 확인할 수 있다.
  • 사용량 조회에 필요한 계정 로그인을 앱 안에서 처리한다. 별도 웹사이트를 오갈 필요가 없다.
  • 일시적인 조회 오류로 사용량이 잘못 급락해 보이는 것을 막는 보정이 들어 있다.

5. 파일과 변경 확인

  • Markdown 뷰어 · 편집기 — 결과 문서를 앱 안에서 바로 읽고 고친다.
  • diff 뷰어 — 무엇이 바뀌었는지 좌우 비교로 확인한다.
  • Git 변경 관리 — 변경 목록 확인, 스테이징, diff 보기를 앱 안에서 처리한다.
  • 이미지 · PDF · 코드 뷰어, 프로젝트 파일 탐색기.

6. 그 밖의 기능

  • 미니 브라우저 — 메인 창 위에 뜨는 작은 브라우저. 세션이 웹 페이지를 열어 읽고 조작할 수 있다.
  • MCP 서버 관리 — 외부 도구 연결을 앱에서 설치·연결·제어한다.
  • 플러그인 · 스킬 관리 — 설치와 상세 확인을 화면에서 처리한다.
  • 자동 업데이트 — 앱은 서명 검증을 거쳐 갱신되고, 사용하는 도구도 시작 시 함께 갱신된다.
  • 단축키 설정과 전역 탭 전환 키, 테마 적용.
