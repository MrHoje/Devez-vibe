# Codex CLI 호환성 자동화 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기준 Codex CLI와 최신 Codex CLI의 app-server 스키마 차이를 CI에서 감지하고 검토 가능한 artifact로 제공한다.

**Architecture:** Node 스크립트가 Codex 설치, `generate-ts` 실행, 기준 스냅샷 비교, Markdown 리포트 생성을 한 곳에서 담당한다. GitHub Actions는 이 스크립트를 기준 검증 또는 최신 감시 모드로 호출하고, 성공·실패와 관계없이 결과물을 artifact로 보관한다.

**Tech Stack:** Node.js 22, npm, Codex CLI, GitHub Actions, unified diff.

## Global Constraints

- 기준 버전과 스키마는 `compatibility/codex-app-server/`만 소유한다.
- 스냅샷은 `codex app-server generate-ts --experimental --out`으로만 갱신한다.
- 기준 검사와 최신 감시는 같은 비교·리포트 코드를 사용한다.
- 설치/생성/비교 실패는 성공으로 전환하지 않는다.
- artifact에는 생성 스키마, unified diff, `compatibility-report.md`만 포함한다.
