# Picker 패널 통일 디자인

## 목적

프롬프트 입력창을 대신하는 선택 화면을 `Commands`와 같은 닫힌 패널 형태로
통일한다. `/model`과 `/effort`의 중복 제목·정보를 제거하고, 패널과 statusline
사이에 시각적 여백을 확보한다.

## 범위

- 공통 `Picker` 오버레이를 `Commands` 스타일의 닫힌 보더로 렌더링한다.
- `/model`, `/effort`, 테마 및 적용 범위 선택 등 같은 `Picker` 렌더링 경로를
  사용하는 화면에 동일한 스타일을 적용한다.
- 일반 프롬프트 입력창이 숨겨지는 모든 오버레이에서 statusline 바로 앞에
  정확히 한 줄의 빈 행을 추가한다.
- 선택, 확정, 취소 및 직접 명령 입력 동작은 변경하지 않는다.

## 패널 구조

패널 제목은 별도 본문 행이 아니라 `Commands`처럼 상단 보더에 포함한다.
본문과 안내문은 좌우 보더 안에 배치하고 하단 보더로 닫는다.

```text
╭─ Effort ───────────────────────╮
│        선택된 effort 보더       │
│ ←→ adjust · Enter · Esc        │
╰────────────────────────────────╯

main │ GPT-5.6-Sol │ ...
```

```text
╭─ Model ────────────────────────╮
│ ❯ GPT-5.6-Sol                  │
│   GPT-5.6-Terra                │
│                                │
│        effort 선택 영역         │
│ Enter · Esc                    │
╰────────────────────────────────╯

main │ GPT-5.6-Sol │ ...
```

- 패널 폭은 현재 오버레이의 가용 폭을 따른다.
- 제목, 모서리, 수평선, 좌우선은 기존 `Commands` 패널의 문자와 톤을 재사용한다.
- 선택된 effort의 작은 닫힌 보더는 그대로 유지한다.
- 키 안내는 패널 내부의 마지막 행에 표시한다.

## 화면별 정리

### `/effort`

- 상단 보더 제목은 `Effort`로 표시한다.
- 본문에 표시되던 현재 모델명은 제거한다.
- effort 단계와 선택 보더만 본문에 표시한다.

### `/model`

- 상단 보더 제목은 `Model`로 표시한다.
- 본문의 독립된 `Effort` 제목 행은 제거한다.
- 모델 목록과 effort 선택 영역은 같은 패널 안에 유지한다.

### 다른 Picker

테마와 적용 범위 선택 화면도 각 화면의 제목을 상단 보더에 넣고 같은 패널 구조를
사용한다. 각 화면의 항목과 키 동작은 유지한다.

## Statusline 여백

일반 프롬프트 입력창이 렌더링되지 않는 오버레이 전체에 공통 규칙을 적용한다.
오버레이 또는 오버레이 전용 입력 영역이 끝난 뒤, statusline을 추가하기 직전에
빈 행 하나를 삽입한다. 기존에 존재하는 여백과 중복되지 않도록 렌더링 경로에서
한 번만 추가한다.

## 구현 경계

- 공통 `Picker` 렌더러에서 보더와 내부 행 패딩을 처리한다.
- `/model`과 `/effort` 상태 데이터에서는 제거 대상인 중복 본문 행만 정리한다.
- statusline 앞 여백은 개별 기능이 아니라 공통 오버레이 프레임에서 처리한다.
- 선택 상태, 명령 처리, 모델 및 effort 적용 로직은 수정하지 않는다.

## 검증

- `/effort`에 모델명이 없고 상단 보더에 `Effort`가 표시되는지 확인한다.
- `/model`에 독립된 `Effort` 행이 없고 상단 보더에 `Model`이 표시되는지 확인한다.
- 선택된 effort의 작은 보더가 유지되는지 확인한다.
- Picker의 모든 본문 행과 안내문이 닫힌 외곽 보더 안에 있는지 확인한다.
- 테마와 적용 범위 Picker도 동일한 보더 구조를 사용하는지 확인한다.
- 프롬프트가 숨겨지는 모든 오버레이와 statusline 사이에 빈 행이 정확히 하나인지
  확인한다.
