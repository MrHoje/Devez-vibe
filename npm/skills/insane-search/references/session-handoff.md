# 사용자 승인 세션 인계

로그인 뒤 공개되는 자료나 사용자가 접근 권한을 가진 페이지에만 사용한다. 브라우저 저장소를 자동 탐색하거나 자격정보를 요구하지 않는다.

## 쿠키 파일

사용자가 직접 내보낸 JSON 또는 Netscape 쿠키 파일을 명시적으로 제공했을 때만 전달한다.

```bash
python3 -m engine "<URL>" --cookie-file "<PATH>" --bundle
```

- 대상 호스트와 일치하는 쿠키만 사용한다. 다른 도메인의 쿠키만 있으면 호출을 거부한다.
- 쿠키 이름·값·파일 경로는 결과, trace, 근거 묶음에 출력하지 않는다.
- HTTP 세션에는 프로세스 메모리에서만 주입한다.
- 브라우저 폴백은 임시 프로필을 사용하고 종료 뒤 삭제한다.
- 미디어 경로에 필요한 Netscape 사본도 임시로 만들고 즉시 삭제한다.
- 원본 쿠키 파일은 엔진이 수정하거나 삭제하지 않는다.

## CAPTCHA

내장 브라우저가 지원하는 공개 챌린지만 자동 처리한다. 강한 CAPTCHA나 계정 확인이 남으면 실패를 숨기지 말고 사용자가 자신의 브라우저에서 직접 완료한 뒤 쿠키를 내보내도록 요청한다. CAPTCHA 대행 서비스, 훔친 세션, 공개 프록시를 자동으로 찾지 않는다.

## 프록시

프록시는 사용자가 제공하거나 명시적으로 승인한 주소만 `--proxy`로 전달한다. 쿠키와 함께 써도 대상 호스트 제한과 비밀정보 비출력 규칙은 그대로 적용된다.
